# 常见问题

## 记忆和上下文窗口有什么区别？
上下文是「每次把历史重新读一遍」，记忆是「把值得留的写下来，下次直接查」。
memcore 把后者独立出来，配门控 + 检索 + 遗忘。

## 需要向量数据库吗？
不需要。`embed` 包用 TF-IDF / BM25 / 特征哈希做稀疏检索，零依赖即可跑。

## 怎么接真实大模型？
把 `llm.provider` 改为 `openai`，填 `endpoint` / `api_key`，门控打分与巩固总结
即切换为真实模型，其余链路不变。

## 写入门控会不会漏掉重要记忆？
会，这是「精确率 vs 召回率」的取舍。默认 threshold=0.45 偏宽松，
可下调 threshold 或改用真实 LLM 打分提升召回。

## 数据存哪？
`memory://` 内存、`json://path` 文件、`sqlite://path` 数据库，URL 决定。
