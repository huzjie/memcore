# 核心概念

## 快记忆 vs 慢记忆

「快慢记忆」借鉴认知科学：快记忆（工作记忆）容量小、速度快、会话内有效；
慢记忆（长期记忆）容量大、跨会话持久、需要「写入/检索/遗忘」机制管理。

memcore 把两者显式分离：
- 快记忆 = `WorkingMemory`，`deque(maxlen=capacity)` 环形缓冲。
- 慢记忆 = `LongTermMemory`，持久化到 store，配门控 + 检索 + 遗忘。

## 写入门控（为什么不是每条都存）

若把每条对话都写入长期记忆，记忆库会迅速退化成一个「聊天日志」，检索噪声大、
成本高。门控用三个信号判断是否值得长期保存：

- **importance**：是否长期有用（偏好 / 事实 / 反复需要）。
- **salience**：显著性启发式（指令词、数字、长度）。
- **novelty**：是否与已有记忆重复。

## 巩固与遗忘

- **巩固**：把多条相关短记忆总结成一条高层记忆，减噪、降本。
- **遗忘**：预算淘汰 + 时间衰减，防止无限膨胀。

## 记忆 vs 上下文

上下文窗口是「每次重新读一遍聊天记录」；记忆是「把值得留的写下来，下次直接查」。
这正是「记忆原生」与「外挂上下文」的本质区别。
